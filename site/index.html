New in v2 — from tool to substrate

v1 made Python code verifiable. v2 makes the model language-neutral and the contracts richer. Every line below ships in v2.0.0 — see the Changelog.

⌘Language-neutral IR + R

Lifted code now hashes to a neutral IR, not Python AST tuples — so a second frontend could land without touching the store. The first one did: sigil lift script.R, plus sigil check-r reproducibility contracts (analyze(seed=42) ≡ #hash), the scientific wedge pytest can't reach.

⟲Multi-fn invariants

invariant round_trip { over: enc, dec verify: dec(enc(x)) == x } — a property across two functions. Patch either one and the invariant re-verifies automatically. One broken edit can't slip through.

!Effect modes & module budgets

!fs.read vs !fs.write, first-class !db, and a whole-module fx: budget every function must satisfy. "This module reads config, never writes, never hits the network" is now a checkable contract.

@@sigil.bind — write plain Python

Decorate an ordinary function; Sigil lifts it on import, checks its declared budget statically, and verifies through the same runner. The .sg language stays for advanced cases — it's no longer the price of entry.

✓CI gate + always-on watch

sigil check --against origin/main fails the build if a bound contract regressed or silently vanished — one line in Actions. sigil watch re-verifies on every save. The seatbelt is always on.

∴Tier-3 propose / validate

Your agent propose_contracts verify clauses; they register provisional and can only bind by passing verification — guesses never launder into specs. sigil from-pytest turns parametrize tables into reviewable goal drafts.

Three guarantees, enforced — not reviewed

Mainstream languages throw away intent; prompts can't be verified. Sigil makes the contract the source of truth and the toolchain its enforcer.

#Content-addressed identity

Every definition is named by the sha256 of its canonical AST. Reformatting, comments, docstrings — hash unchanged (proven by property tests, 200 random mutations a run). Any semantic change — hash moves. "Did the AI change the logic?" is a string compare.

!Effects are typed

Every function carries its effect row: !net !fs !rand !clock !env… A goal's budget is checked statically; a sneaked-in write fails the build naming the exact call chain. When analysis can't see through dynamic code it says !unsafe? — uncertainty is never silenced.

∴Verify before display

Goals declare executable verify: clauses. Implementations run them subprocess-isolated with timeouts; a pass binds goal↔impl in the store, anything else stays provisional. Patches are auto-verified before success is ever shown.

R1Append-only context

The digest sheet never rewrites history — your cached prompt prefix stays byte-stable. Proven with a hypothesis property over arbitrary op sequences.

R2Expand, don't regenerate

expand(#hash) is byte-identical forever. Re-reading code is cheap cached input; re-emitting it from memory is expensive output.

R3Verify before display

Failures return the failing clause, observed values, and the subtree hash to patch — never “try again from scratch”. The retry term is the one that dominates cost.

Quick Guide

From zero to a verifying, patch-driven codebase — for humans first, then for your agents. Everything here is copy-paste real; full docs live in docs/.

1 · Setup

1.1
Requirements: Python 3.11+ and pip. From the sigil-build/ repo root:
pip install -e ".[dev,harness]"   # core + tests + MCP server
sigil --version                    # sigil 2.0.1

Core installs are lean: stdlib + cbor2. The [harness] extra adds the mcp package for sigil serve; [dev] adds pytest/hypothesis/ruff.

2 · Everyday CLI

2.1
Lift existing Python — parse-only, never executes your code. Add --json for machines.
sigil lift path/to/your/code
; one line per definition:
#d4b8 fetch_user(user_id) -> ? !clock !fs !net
2.2
Build a Sigil module — transpiles to Python, checks the effect budget statically, registers goals in a .sigil/ store.
sigil build prices.sg --store . --json
# writes prices.py + test_fetch_prices.py; prints goal hashes
2.3
Verify a goal — subprocess-isolated, timeout-guarded, cached by (goal, impl) hash. Goals with in: parameters need an inputs file.
echo '{"tickers": ["AAPL"], "start": "a", "end": "b"}' > inputs.json
sigil verify '#a1b2c3d4' --store . --inputs inputs.json
# verify fetch_prices: pass (140ms) → goal status: verified · re-runs are <50ms cache hits

Exit codes: 0 ok / verify pass · 1 verify fail · 2 usage or build rejection · 3 unexpected (never a traceback). Set SIGIL_RELEASE=1 to strip contract assertions from transpiled code in production.

2b · New in v2 — modes, R, invariants, CI

2.4
Write plain Python — @sigil.bind lifts on import and checks the budget statically.
import sigil

@sigil.bind(verify=["out == n * 3"], fx="pure", inputs={"n": 4})
def triple(n):
    return n * 3
# importing registers goal+impl; sigil verify (or check) binds on pass

Effect modes & a module budget — read-only is a contract now.
module config_io

{ ret parse(open(p).read()) }

  in: x Int

2.7
Lift R + reproducibility contract (lifting needs no R; check-r needs Rscript).

4 · Patch ops in 30 seconds

Ops address the canonical form shown by expand. Path tokens are dict keys, list indices, or host-AST field names; op ∈ replace insert delete. Literals end in .val. Malformed ops fail with the op index + failing token (code: bad_path) — re-expand and re-derive, don't guess twice.

-- Sigil-written fn: change a constant
{"path": "body.stmts.0.value.right.val", "op": "replace", "value": "3"}
-- lifted code: a neutral IR sits under body.data (v2.0). A def is ["def", name, args, [body]...];
-- derive paths from expand(hash, form="canonical"), or skip path authoring with patch_snippet
{"path": "body.data.3.0.1.2", "op": "replace", "value": "30.0"}

Easiest of all — patch_snippet: send the whole corrected definition and Sigil computes the minimal ops for you (snippet ≡ re-lift, by hash).

patch_snippet("#6e01", "fn triple(n Int) -> Int\n  pure\n{\n  ret n * 3\n}", {"n": 4})
-- grow / shrink statement lists
{"path": "body.stmts.1", "op": "insert", "value": { ...stmt data... }}
{"path": "body.stmts.1", "op": "delete"}

  • expand(hash, form="canonical") exposes the patch-path schema; patch returns the display hash; __sigil_* scaffolding filtered from sheets.
  • Distribution renamed sigil-lang — the PyPI name "sigil" was taken (and shadowing the test install). Import + CLI stay sigil.
